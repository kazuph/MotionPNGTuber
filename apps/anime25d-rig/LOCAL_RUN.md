# Anime2.5DRig / DokochanをmacOSで起動する

必要なものはPython 3とブラウザです。実行にnpm、SSH、GPU、See-throughの再推論は不要です。PSD・調整JSON・ブラウザ用JS/WASMは同梱しています。

1. このフォルダの `start_macos.command` をダブルクリックします。Python 3が見つからないときはPython 3をインストールしてから起動してください。
2. ブラウザで `http://127.0.0.1:8016/` が開きます。開かないときはこのURLをブラウザに入力してください。
3. 上部または空画面の **サンプルC（Dokochan）** を押すと、同梱PSDと対応する調整JSONを一緒に読み込みます。サンプルA/Bも同じ画面から選べます。
4. 停止するときは起動したターミナルで `Ctrl+C` を押します。8016が使用中なら、そのアプリを確認してください。同じサーバーを重ねて起動する必要はありません。

ターミナルからは、このフォルダで `./start_macos.command`、または `python3 obs_server.py --port 8016 --open-browser` を実行できます。ブラウザを自動で開かない場合は `--open-browser` を省きます。

OBSのブラウザソースには `http://127.0.0.1:8016/?obs=1` を指定します。カメラ・マイクは必要なときだけ画面から有効にし、ブラウザの許可は本人が操作してください。アンカー編集中は静止ポーズになり、カメラの動きは適用されません。

PSDと調整JSONの保存・読み込み、透過WebM録画はアプリの既存操作を使います。Dokochanの閉じ目・閉じ口には公式の自動補完を含み、元の開口素材は閉口線なので実際に口を開けた見た目にはなりません。原素材由来の微小な透明穴と環境依存の録画フレームレートは残っています。

公式ソースの出典・固定commitは [UPSTREAM.json](UPSTREAM.json)、ライセンスは [LICENSE](LICENSE)、カメラ用同梱ファイルの出典は [NOTICE.md](lib/vendor/face_mesh/NOTICE.md) を参照してください。
