ⓘ このマップは何か / 何でないか

これは: irodori TTSに多様なキャプション×seedで実際に生成させた音声群を、話者照合モデル（ECAPA-TDNN）が測った「同じ人の声か」の類似度で並べた地図。点はすべて実在する生成音声で、クリックすると即試聴できる。近くの点ほど似た声で、クラスタはモデルが得意とする「声の型」を表す。

これではない: 連続的に声が変化する魔法の空間ではない。点のない空白はモデルがその中間の声をあまり持たないことを示し、空白クリックは「近傍k=4点のキャプション隠れ状態の距離重みブレンド」による近似合成（◆）。同じ声の塊（同一キャプションのseed違い）の中では声はほとんど変わらない — それはマップが声質を忠実に保存している証拠でもある。

★類似度の読み方（ECAPA話者照合スコア）: 0.6以上=ほぼ同一人物級 / 0.4〜0.6=同系統の声 / 0.4未満=別系統。マスターの正解音源とアトラス声の最高値は ユナ≈0.61・聡子≈0.50 — つまり「captionからユナにそこそこ近い声は出せるが、聡子級は出せない」がこのモデルの正直な限界。

軸の意味: UMAP/PCAの軸は学習されたものなので絶対的な意味はないが、音響特徴とのSpearman相関（マップ四隅に表示）で事後的に解釈できる。
